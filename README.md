# 🌐 christosp — Personal Portfolio Website

A responsive portfolio website built with **Next.js**, **Tailwind CSS**, and **TypeScript**.  
It showcases my projects, skills, and contact details — serving as my central hub for all my full-stack work.

---

## 🚀 Features
- Responsive layout with **dark/light mode**
- Projects page with live demos & GitHub links
- SEO-optimized metadata and OpenGraph images
- Contact form (integrates with FastAPI backend)
- Deployed on **Vercel**

---

## 🛠️ Tech Stack
- **Frontend:** Next.js, TypeScript, Tailwind CSS  
- **Hosting:** Vercel  
- **Version Control:** Git & GitHub

---

## ⚙️ Setup
```bash
git clone https://github.com/ChrisPa691/christosp.git
cd christosp
npm install
npm run dev
```
Visit [http://localhost:3000](http://localhost:3000)
